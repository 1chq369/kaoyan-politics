1840年6月
史纲

鸦片战争爆发

史纲·上编·第一章
🧠 记忆锚点：一声炮响，性质两半，矛盾两对，任务两条。

近代史起点，社会性质开始质变。

★ 关键考点
  • 中国近代史的起点：社会性质由封建社会变为半殖民地半封建社会
  • 社会主要矛盾变为两对，民族矛盾成为最主要的矛盾
  • 两大历史任务：争取民族独立、人民解放（前提）；实现国家富强、人民幸福（目的）
⚠ 易混辨析
  • 易混：1840 是“起点”，1842 是“正式形成”；半殖民地讲主权，半封建讲经济
  • 考法：问“近代中国一切社会问题和革命问题的总根源”→ 半殖民地半封建的社会性质
深度理解 · 背景 / 矛盾 / 任务

历史背景：英国为扭转鸦片贸易逆差、打开中国市场，以虎门销烟为借口发动侵华战争。清军战败，1842年被迫签订《南京条约》。

根本矛盾：帝国主义与中华民族、封建主义与人民大众的矛盾，此后贯穿整个近代中国。

历史任务：反帝反封建，争取民族独立和人民解放，实现国家富强和人民幸福。

1842年8月29日
史纲

《南京条约》签订

史纲·上编·第一章
🧠 记忆锚点：割岛、赔款、开口、协定关税，四件事。

第一个不平等条约，社会性质定型。

★ 关键考点
  • 中国近代第一个不平等条约，半殖民地半封建社会由此正式形成
  • 五口通商使中国被卷入世界资本主义市场，自然经济开始解体
  • 协定关税破坏关税自主权，是列强经济侵略的制度性开端
⚠ 易混辨析
  • 易混：割香港岛 ≠ 割香港地区。香港岛1842、九龙司1860、新界1898
  • 考法：最能体现“半殖民地”的是领事裁判权与协定关税，最能体现“半封建”的是自然经济解体
深度理解 · 背景 / 矛盾 / 任务

历史背景：战败签约：割香港岛、赔款2100万银元、开放五口通商、协定关税，中国开始丧失关税自主权。

根本矛盾：帝国主义与中华民族的矛盾上升为最主要的矛盾。

历史任务：推翻帝国主义和封建主义统治，改变半殖民地半封建社会形态。

1851年1月11日
史纲

金田起义·太平天国运动

史纲·上编·第二章
🧠 记忆锚点：金田举旗、天京建都、天朝田亩、资政新篇。

农民阶级救国方案的最高峰。

★ 关键考点
  • 农民阶级探索国家出路的最高峰，也是旧式农民战争的最高峰
  • 《天朝田亩制度》以绝对平均主义为核心，具有空想性
  • 失败证明：农民阶级不是新的生产力和生产关系的代表
⚠ 易混辨析
  • 易混：《天朝田亩制度》= 空想平均主义（1853）；《资政新篇》= 第一个发展资本主义的方案（1859）
  • 考法：太平天国“新”在哪里 → 反对封建土地所有制、提出发展资本主义方案
深度理解 · 背景 / 矛盾 / 任务

历史背景：洪秀全在广西桂平金田村起义，建号太平天国，两年后攻占南京定都，建立与清政府对峙的农民政权。

根本矛盾：封建主义与人民大众的矛盾空前尖锐，农民阶级被迫起义。

历史任务：推翻清朝统治，建立“人间天国”，实质仍是改朝换代的农民战争。

1853年3月
史纲

定都天京·《天朝田亩制度》

史纲·上编·第二章
🧠 记忆锚点：一个空想，一个超前，都落不了地。

理想纲领与空想局限并存。

★ 关键考点
  • 《天朝田亩制度》：平均分配土地，最能体现太平天国的社会理想
  • 《资政新篇》：中国近代第一个发展资本主义的方案，但缺乏实施条件
  • 两者都未能真正实行，反映农民阶级的历史局限
⚠ 易混辨析
  • 易混：前者反封建但空想，后者先进但脱离农民现实
  • 考法：太平天国没能救中国，根因是阶级局限而非军事失败
深度理解 · 背景 / 矛盾 / 任务

历史背景：太平军攻占南京改名天京，颁布《天朝田亩制度》；1859年洪仁玕提出《资政新篇》。

根本矛盾：农民阶级与地主阶级的矛盾，同时面临中外反动势力联合镇压。

历史任务：建立“有田同耕、有饭同食、无人不饱暖”的理想社会。

1856年10月23日
史纲

第二次鸦片战争

史纲·上编·第一章
🧠 记忆锚点：1856—1860，四国联军，一炬圆明园。

半殖民地化加深，主权进一步丧失。

★ 关键考点
  • 半殖民地化程度进一步加深，内河航行权、领事裁判权进一步扩大
  • 外国公使进驻北京，侵略势力由沿海深入内地
  • 清政府“借师助剿”，出现中外反动势力公开勾结
⚠ 易混辨析
  • 易混：第二次鸦片战争是“鸦片战争的继续和扩大”，不是新性质的战争
  • 考法：为什么说“进一步加深”→ 侵略区域由五口到沿海沿江，侵略方式由商品输出转向资本输出准备
深度理解 · 背景 / 矛盾 / 任务

历史背景：英法为扩大侵略权益发动战争，1860年攻入北京、焚毁圆明园；战后签订《天津条约》《北京条约》。

根本矛盾：帝国主义与中华民族、封建主义与人民大众的矛盾。

历史任务：反帝反封建，争取民族独立和人民解放；旧民主主义革命由农民阶级、地主阶级洋务派、资产阶级先后探索，均未成功。

1860年10月
史纲

《北京条约》·火烧圆明园

史纲·上编·第一章
🧠 记忆锚点：英法烧园，俄国割地。

主权大量丧失，边疆危机开始。

★ 关键考点
  • 割九龙司地方一区，中国丧失更多领土
  • 增开天津为商埠，侵略势力直逼京畿
  • 俄国趁火打劫，侵占中国东北、西北150多万平方公里领土
⚠ 易混辨析
  • 易混：割九龙司（1860）与租借新界（1898）性质不同
  • 考法：近代割占领土最多的国家是俄国，不是英国
深度理解 · 背景 / 矛盾 / 任务

历史背景：英法联军攻入北京，焚毁圆明园，迫使清政府签订《北京条约》：割九龙司、增开天津等商埠、赔款增加。

根本矛盾：帝国主义侵略势力与中华民族的矛盾进一步激化。

历史任务：挽救民族危机，学习西方器物以自强。

1861年起
史纲

洋务运动兴起

史纲·上编·第二章
🧠 记忆锚点：中体西用，只学器物，甲午一战全露。

器物层面的自救，注定失败。

★ 关键考点
  • 指导思想“中学为体、西学为用”，只学器物不改制度
  • 客观上刺激了民族资本主义产生，是中国近代化的开端
  • 甲午战败标志洋务运动破产：地主阶级洋务派不能救中国
⚠ 易混辨析
  • 易混：“近代化开端”是客观作用，主观目的仍是维护封建统治
  • 考法：洋务运动失败的根本原因 → 不触动封建根基的“中体西用”
深度理解 · 背景 / 矛盾 / 任务

历史背景：奕䜣、曾国藩、李鸿章等以“自强”“求富”为口号，创办近代军事工业、民用工业，建立新式海军。

根本矛盾：封建统治阶级内部自救与外国资本主义侵略的矛盾交织。

历史任务：师夷长技以自强，维护清朝封建统治。

1864年7月
史纲

天京陷落·太平天国失败

史纲·上编·第二章
🧠 记忆锚点：农民能打，不能领路。

农民战争的历史局限集中暴露。

★ 关键考点
  • 农民阶级不是新的生产力和生产关系的代表，无法领导中国革命胜利
  • 没有科学理论指导，不能提出切实可行的救国方案
  • 启示：中国革命必须由先进阶级领导、以科学理论为指导
⚠ 易混辨析
  • 易混：太平天国失败是“阶级局限”，义和团失败是“阶级局限＋笼统排外”
  • 考法：三大农民运动的共同结论 → 农民阶级不能领导中国革命胜利
深度理解 · 背景 / 矛盾 / 任务

历史背景：湘军攻陷天京，太平天国运动在中外反动势力联合镇压下失败。

根本矛盾：农民阶级与地主阶级、外国侵略势力的矛盾。

历史任务：推翻封建统治，建立农民政权。

1883年12月
史纲

中法战争

史纲·上编·第一章
🧠 记忆锚点：镇南关大捷，纸面上还是输了。

军事胜利、外交失败的典型。

★ 关键考点
  • “不败而败”，暴露清政府妥协投降本质
  • 列强进一步打开中国西南门户
  • 边疆危机全面加深，刺激瓜分狂潮
⚠ 易混辨析
  • 易混：中法战争“不败而败”，甲午战争“战败签约”
  • 考法：最能说明清政府腐败的是中法战争的结果
深度理解 · 背景 / 矛盾 / 任务

历史背景：法国侵略越南并进犯中国西南，冯子材取得镇南关大捷，清政府仍签订《中法新约》。

根本矛盾：帝国主义与中华民族的矛盾在边疆地区集中爆发。

历史任务：保卫边疆，抵御列强蚕食。

1894年7月25日
史纲

甲午中日战争

史纲·上编·第一章
🧠 记忆锚点：甲午一败，器物路线终结。

洋务破产，救亡升级。

★ 关键考点
  • 洋务运动破产，“中体西用”方案彻底失效
  • 民族危机空前严重，各阶级救亡运动高涨
  • 证明只学器物不改制度不行，直接推动维新变法
⚠ 易混辨析
  • 易混：甲午战争是“洋务运动破产”的标志，不是“近代化开端”
  • 考法：甲午战后列强侵华方式由商品输出为主转为资本输出为主
深度理解 · 背景 / 矛盾 / 任务

历史背景：日本蓄意发动侵华战争，北洋海军全军覆没，1895年被迫签订《马关条约》。

根本矛盾：帝国主义与中华民族的矛盾空前激化。

历史任务：救亡图存，探索新的救国道路。

1895年4月17日
史纲

《马关条约》签订

史纲·上编·第一章
🧠 记忆锚点：两亿两、割台湾、开厂子。

瓜分狂潮的起点。

★ 关键考点
  • 割地最多、赔款最巨，半殖民地化程度大大加深
  • 允许在华设厂，标志列强侵华进入资本输出阶段
  • 引发瓜分狂潮，台湾人民掀起反割台斗争
⚠ 易混辨析
  • 易混：《马关条约》“设厂”是资本输出，《南京条约》“协定关税”是商品输出
  • 考法：台湾被割占始于1895年，1945年抗战胜利回归
深度理解 · 背景 / 矛盾 / 任务

历史背景：割台湾及澎湖列岛、赔款2亿两白银、开放沙市重庆等口岸、允许日本在华设厂。

根本矛盾：帝国主义列强与中华民族的矛盾全面激化。

历史任务：挽救民族危亡，变革社会制度。

1898年6月11日
史纲

戊戌变法（百日维新）

史纲·上编·第二章
🧠 记忆锚点：103天，改良路线到此为止。

改良路线的失败与启蒙价值。

★ 关键考点
  • 资产阶级改良道路在中国走不通
  • 具有重要的思想启蒙意义，推动了资产阶级革命运动
  • 维新派企图依靠皇帝、脱离群众，是其失败主因
⚠ 易混辨析
  • 易混：戊戌变法＝改良（保留君主）；辛亥革命＝革命（推翻君主）
  • 考法：戊戌变法最深远的影响是思想启蒙，不是政治改良
深度理解 · 背景 / 矛盾 / 任务

历史背景：康有为、梁启超等推动光绪帝下诏变法，主张君主立宪，仅103天即被慈禧镇压。

根本矛盾：资产阶级维新派与封建顽固势力的矛盾。

历史任务：变法图强，走自上而下的改良道路。

1900年6月
史纲

义和团运动·八国联军侵华

史纲·上编·第一章
🧠 记忆锚点：扶清灭洋，扶错了对象。

反帝高潮与阶级局限并存。

★ 关键考点
  • 农民阶级反帝爱国运动的高潮，但笼统排外暴露局限性
  • “扶清灭洋”看不清清政府本质，被利用后又被抛弃
  • 清政府成为“洋人的朝廷”，彻底暴露其本质
⚠ 易混辨析
  • 易混：义和团“扶清灭洋”是落后性口号，不是科学纲领
  • 考法：义和团失败说明单纯农民战争不能完成反帝任务
深度理解 · 背景 / 矛盾 / 任务

历史背景：义和团以“扶清灭洋”为口号反帝，八国联军攻占北京，清政府被迫签订《辛丑条约》。

根本矛盾：帝国主义与中华民族的矛盾达到顶点。

历史任务：反抗侵略，挽救民族危机。

1901年9月7日
史纲

《辛丑条约》签订

史纲·上编·第一章
🧠 记忆锚点：四亿五千万，一人一两，彻底沉沦。

半殖民地半封建社会的最终形成。

★ 关键考点
  • 中国完全沦为半殖民地半封建社会
  • 清政府完全成为帝国主义统治中国的工具
  • 使馆界驻兵使中国丧失首都安全主权
⚠ 易混辨析
  • 易混：《辛丑条约》标志“完全沦为”，不是“开始沦为”
  • 考法：最能说明清政府是“洋人朝廷”的是“禁止人民反帝”条款
深度理解 · 背景 / 矛盾 / 任务

历史背景：赔款4.5亿两、划东交民巷为使馆界、拆炮台允许驻兵、禁止人民反帝。

根本矛盾：帝国主义与中华民族的矛盾成为中国社会最主要的矛盾。

历史任务：推翻清王朝，完成民族独立和人民解放。

1905年8月20日
史纲

中国同盟会成立

史纲·上编·第三章
🧠 记忆锚点：1905 东京，三民主义出炉。

资产阶级革命有了统一政党与纲领。

★ 关键考点
  • 第一个全国性的资产阶级革命政党
  • 三民主义：民族、民权、民生
  • 旧三民主义缺乏明确的反帝要求和彻底的土地纲领
⚠ 易混辨析
  • 易混：旧三民主义（1905）与新三民主义（1924）的区别在反帝反封建的彻底性
  • 考法：同盟会成立标志资产阶级革命派登上历史舞台并走向成熟
深度理解 · 背景 / 矛盾 / 任务

历史背景：孙中山在东京联合各革命团体成立中国同盟会，提出“驱除鞑虏、恢复中华、创立民国、平均地权”。

根本矛盾：资产阶级革命派与封建专制统治的矛盾。

历史任务：推翻清朝统治，建立资产阶级共和国。

1911年10月10日
史纲

武昌起义

史纲·上编·第三章
🧠 记忆锚点：1911 武昌，帝制落幕，性质未变。

帝制终结，共和肇建。

★ 关键考点
  • 辛亥革命爆发，推翻两千多年的君主专制制度
  • 资产阶级共和国方案在中国第一次付诸实践
  • 没有提出彻底的反帝反封建纲领，未能改变社会性质
⚠ 易混辨析
  • 易混：推翻“君主专制制度”≠推翻“封建制度”（后者到1956年才完成）
